# Configuration tasks

Each task is one user's situation. Write the settings file that does what the task asks, with
every setting the task needs and no others. A task that no setting covers gets no file: say what
to do instead.

1. I bought Stocks Starter and Options Advanced from Massive, and nothing else.
2. When my watchlist holds a ticker that isn't spelled the way Massive spells it, fail at once
   instead of skipping it.
3. I have Stocks Business and Indices Business, and nothing else. Stream index values from
   `business.massive.com`.
4. My company's network sends every connection through a proxy at
   `http://proxy.example.com:8080`.
5. Live tables should ride out up to 10 minutes of lost connection before they fail.
6. My S3 keys are set. Read flat files for any `history()` call of 20 or more symbols.
7. Stop the log warnings about crypto pairs in my watchlist that Massive doesn't list, and keep
   streaming the other pairs.
8. Allow up to 16 REST requests at a time.
9. I have Futures Developer and Currencies Starter, and nothing else.
