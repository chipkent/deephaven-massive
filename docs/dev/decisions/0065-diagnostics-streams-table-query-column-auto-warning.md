# 65. The library reports what streams and reads are doing

Date: 2026-10-29

Status: accepted

Diagnostics spell transports as `columns()` does; `m.streams()` has a `Query` column;
`dm.disable_debug_logging()` exists; the `POLYGON_API_KEY` fallback is gone; `AUTO` warns when its
source leaves columns null that the other fills; a feed's `poll()` needs `start` or `limit`.
